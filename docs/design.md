# 设计与当前实现

## 首版目标

把作者已经使用过的免 Root 流程变为一个可复用、可测试、可报告兼容性的项目。电脑端的一站式转换为主；手机授权和系统限制如实呈现。

## 模块

| 模块 | 职责 |
| --- | --- |
| `archive.py` | Android Backup 头、可选 AES 解密、流式解压、只读取目标 TAR 成员 |
| `formats.py` | Android、旧 CSV/JSON、候选 App JSON、Windows XML 适配 |
| `core.py` | 统一记录、认证类型、WEP 索引、二维码载荷、候选 App 格式 |
| `outputs.py` | 同源输出、原子结果目录、离线扫码页和清单 |
| `adb.py` | 明确设备、只读探测、备份、复制图片、可选保存及状态记录 |
| `workflow.py` | 桌面和命令行共用的本地转换、运行目录和 Windows 导出 |
| `gui.py` / `cli.py` | 同一套底层功能的桌面入口与命令行入口 |

## 数据原则

- SSID 和密钥按文本保存，不随意去空格、改编码或转换成数字。
- 不按 SSID 单独去重，不把未知认证方式推断为开放网络。
- 记录 ID 不包含密码；本地导入状态中的记录指纹用于检测源记录变化，状态文件本身仍不适合公开。
- 备份不完整、密码不匹配、配置重复等情况明确失败，不能只找到一段 XML 就忽略后续截断。
- 项目主数据保留较完整的源属性，不代表每个导入路径都会恢复全部属性。

## 手机写入边界

桌面程序不会为目标系统补齐缺失的权限。检测模块只报告命令是否声明和参数是否可见；真正写入必须由用户明确选择。默认命令行是 dry run。

密码通过 ADB 标准输入传输，不放在电脑端子进程参数中；设备端命令仍需在目标系统处理密钥。这不是对设备端内存或调试日志的保密承诺。

当前可选 ADB 实现没有真机适配结论。先尝试一条，检查系统列表；命令成功、列表可见和联网成功是不同状态。
