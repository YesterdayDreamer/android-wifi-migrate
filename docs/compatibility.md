## 分开报告五件事

1. ADB 能连接并获授权。
2. 旧机备份包含真实 WiFi 配置与可读取密钥。
3. Shizuku 能启动（仅当使用该路线）。
4. 目标机接受配置，并可在系统已保存网络中读回。
5. 在有对应网络时实际联网成功。

其中任何一项不能代替另一项。Android API 版本达到最低要求也不等于厂商保留了全部接口。

## 不承诺的范围

- 不绕过系统权限、不解锁 Bootloader、不获取 Root。
- 不把历史 ADB backup 当作所有新系统的永久通道。
- 不支持任意厂商的私有加密备份格式；加密 Android Backup v1 的旧 PBKDF2 兼容模式也未实现。
- 不把企业证书网络转为个人密码网络，不擅自把纯 SAE/OWE 降为其他认证方式。
- 不把鸿蒙 4 的 Android 兼容路径推广到不提供 Android APK/ADB 路径的系统。
- 不承诺手机在网络不在附近时都能通过扫码保存。
